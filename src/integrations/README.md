# Будущие интеграции

Этот каталог зарезервирован для адаптеров Supabase и серверного API записи.
Сейчас нет SDK, сетевых запросов записи, хранения данных или Telegram-бота.

На следующем этапе: определить схему услуг, мастеров и свободных слотов; настроить Supabase RLS; создать серверный endpoint для подтверждения записи и уведомления Telegram. Токен Telegram и service-role ключ Supabase должны находиться только на сервере. Тип BookingIntent в ../types/index.ts — отправная точка для контракта, а не реализация записи.
